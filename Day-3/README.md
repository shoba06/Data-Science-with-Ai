# 📘 Day 3 - Data Science with AI Bootcamp

## 📅 Date
15 April 2026

## ✅ Task Description
Worked on real-world datasets to perform data cleaning, exploratory data analysis (EDA), and data visualization. 
This task focused on understanding how data can be transformed into meaningful insights.

## 📂 Datasets Used
- 🏠 House Price Dataset  
- 🚢 Titanic Dataset  
- 🚗 Automobile Dataset  

## 📌 Topics Covered
- Data Loading using Pandas  
- Handling Missing Values (fillna, drop)  
- Data Transformation (rename, astype)  
- Exploratory Data Analysis (EDA)  
- Correlation Analysis  
- Data Visualization  

## 🔍 Key Operations Performed
- Checked and handled missing values using `isnull()`  
- Cleaned dataset by filling and dropping unnecessary data  
- Renamed columns for better readability  
- Converted data types for proper analysis  
- Used `value_counts()` and `groupby()` for insights  
- Generated correlation matrix using `.corr()`  

## 📊 Visualizations Created
- Heatmap to analyze feature relationships  
- Scatter plots to identify trends between variables  
- Histograms to understand data distribution  

## 💡 Key Insights
- Larger living area leads to higher house prices  
- Engine size and horsepower strongly influence car price  
- Higher mileage (mpg) is negatively related to price  
- Data visualization helps in identifying hidden patterns

- Python  
- Pandas  
- NumPy  
- Matplotlib
