# 📘 Day 5 - Data Science with AI Bootcamp

## 📅 Date
17 April 2026

## ✅ Task Description
Built a classification model using Logistic Regression on the Titanic dataset to predict passenger survival. 
This task focused on applying supervised learning techniques and evaluating model performance.

## 📂 Dataset Used
- 🚢 Titanic Dataset (Kaggle - Machine Learning from Disaster)

## 📌 Topics Covered
- Logistic Regression (Classification)  
- Data Preprocessing  
- Handling Missing Values  
- Encoding Categorical Data  
- Model Evaluation  

## 🔍 Key Operations Performed
- Loaded dataset using Pandas  
- Handled missing values in Age and Embarked columns  
- Encoded categorical features (Sex, Embarked)  
- Selected relevant features for prediction  
- Split data into training and testing sets  
- Trained Logistic Regression model using scikit-learn  
- Generated predictions using the trained model  

## 📊 Evaluation Metrics Used
- Accuracy Score  
- Confusion Matrix  
- Classification Report (Precision, Recall, F1-score)  

## 💡 Key Insights
- Logistic Regression is effective for binary classification problems  
- Gender and passenger class significantly influence survival  
- Feature engineering (FamilySize) improved model performance  
- Achieved accuracy above 80%  

## 💻 Tools Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  
- Google Colab
