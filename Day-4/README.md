# 📘 Day 4 - Data Science with AI Bootcamp

## 📅 Date
16 April 2026

## ✅ Task Description
Built and evaluated regression models using the House Price Prediction dataset. 
This task focused on applying machine learning techniques to predict house prices.

## 📂 Dataset Used
- 🏠 House Price Dataset  

## 📌 Topics Covered
- Simple Linear Regression  
- Multiple Linear Regression  
- Polynomial Regression  
- Model Evaluation Metrics  

## 🔍 Key Operations Performed
- Selected relevant features for prediction  
- Split dataset into training and testing sets  
- Built regression models using scikit-learn  
- Generated predictions using trained models  
- Evaluated models using performance metrics  

## 📊 Evaluation Metrics Used
- Mean Squared Error (MSE)  
- Mean Absolute Error (MAE)  
- R² Score  

## 💡 Key Insights
- Simple Linear Regression gives basic predictions  
- Multiple Linear Regression improves accuracy  
- Polynomial Regression captures complex relationships  
- Model performance improves with better feature selection  

## 💻 Tools Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  
- Google Colab
